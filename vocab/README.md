# vocab/

Controlled vocabulary and its comparison against the GT. These files are data (or regenerated), so their notes live here, not in the files.

| File | Purpose | Use case | Example |
|------|---------|----------|---------|
| `controlled-vocabulary.json` | The approved label lists: 8 intents, 31 sub_intents, 4 APIs, 6 providers, owners, tools, qualification fields. | Read by `map_gt.py` and the validator; mapped labels must come from here. | `"tools": ["doc_search", "calculator", "update_record", "escalate_ticket"]`, `"tools_dropped": []`. |
| `vocab-diff-gt-v2_4.json` / `.md` | Generated by the validator: GT v2.4 labels vs the vocabulary. | Proves GT and vocabulary agree. | "Vocabulary differences: **0**". |
| `vocab-diff-gt-v2_3.json` / `.md` | Same comparison against GT v2.3, kept as history (no longer regenerated). | Traceability for the v2.3 sync. | "Vocabulary differences: **0**" against `gt_v2_3.xlsx`. |
